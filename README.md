# Bank_ML_Classification_Spark
PySpark ML pipeline for binary classification on the UCI Bank Marketing dataset. Data science lifecycle: EDA, class imbalance correction via oversampling, feature engineering with StringIndexer + OneHotEncoder, and comparison of 5 classifiers (Logistic Regression, Decision Tree, Random Forest, GBT, SVM) evaluated on Accuracy, F1-Score, and ROC-AUC.
